### Credit Card Transaction & Customer Analytics | SQL + Power BI

This project analyzes one year of credit card transaction and customer data for a financial services portfolio. The objective was to build an **end-to-end analytics pipeline**, transforming raw multi-table data into a structured analytical model using SQL and delivering an interactive **two-page Power BI dashboard** focused on transaction performance and customer demographics.

The dataset consisted of four source files:

* Credit Card Transaction Records
* Transaction Additions
* Customer Profile Data
* Customer Profile Additions

Because the data was distributed across multiple related tables, **relational joins and data transformation techniques** were used to create a unified analytical dataset. SQL was used for data exploration, cleaning, validation, joins, aggregations, and KPI calculations, while Power BI was used to develop interactive visualizations, measures, filters, and dashboards.

### Dashboard Pages

* **Page 1 – Transaction Performance:** Transaction volume, revenue/spending trends, transaction categories, card usage, and key financial KPIs.
* **Page 2 – Customer Demographics:** Customer segmentation, demographics, geographic distribution, income-related insights, and customer behavior patterns.

### Key Skills Demonstrated

**SQL | Data Cleaning | Data Transformation | Relational Data Modeling | Joins | Aggregations | KPI Analysis | Power BI | DAX | Data Visualization | Dashboard Development | Business Insights**
